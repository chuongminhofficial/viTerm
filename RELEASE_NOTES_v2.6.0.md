# viTerm 2.6.0

Frontend mới bổ sung Server Control Center, hướng dẫn Spotlight, kiểm tra nhiều host, tự khóa khi không hoạt động và thông báo cập nhật từ backend.

Phát hành sau khi pipeline build thành công đủ các bộ cài:

| Hệ điều hành | Bộ cài |
| --- | --- |
| Windows x64 | Setup EXE, Portable EXE |
| macOS Intel / Apple Silicon | DMG, ZIP theo kiến trúc |
| Linux x64 | AppImage, DEB |

Portable tự giải nén rồi chạy, yêu cầu WebView2 Runtime; dữ liệu dùng thư mục app data thông thường.
Bản build chưa ký số/notarize. Checksum chính xác được tạo trong SHA256SUMS.txt ở bước phát hành.
